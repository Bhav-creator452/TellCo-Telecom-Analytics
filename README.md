# TellCo Telecom Analytics

An end-to-end Telecom User Analytics and Machine Learning platform developed as part of the NextHikes Data Science Internship.

## Project Overview

This project analyzes telecom xDR (data session records) to understand customer behavior, engagement, network experience, and satisfaction.

The objective is to extract actionable business insights and evaluate growth opportunities for TellCo, a mobile service provider.

## Analytical Modules

1. **User Overview Analysis** – Customer behavior, handset analysis, application usage and exploratory data analysis.
2. **User Engagement Analysis** – Customer engagement metrics, segmentation and K-means clustering.
3. **User Experience Analysis** – Network performance, TCP retransmission, RTT, throughput and handset analysis.
4. **User Satisfaction Analysis** – Customer scoring, satisfaction prediction and segmentation.

## Technology Stack

- Python
- Pandas and NumPy
- Matplotlib, Seaborn and Plotly
- Scikit-learn
- Streamlit
- MLflow
- Pytest
- Docker
- GitHub Actions

## Project Structure

The project follows a modular Python package architecture with separate components for data ingestion, preprocessing, feature engineering, analytics, machine learning, visualization, testing and deployment.
